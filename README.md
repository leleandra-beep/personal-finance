# Personal Finance CLI

Backend-приложение на Java (CLI) для управления личными финансами:
несколько пользователей, доходы/расходы, категории и бюджеты,
статистика, переводы между кошельками, сохранение состояния в файл.

## Требования
- JDK 17+
- Maven 3.8+

## Сборка и запуск
```bash
mvn clean package
java -jar target/personal-finance.jar
# либо
mvn exec:java -Dexec.mainClass="com.finance.Main"
```

По умолчанию данные сохраняются в `wallets.txt` в рабочей директории.
Другой путь:
```bash
java -jar target/personal-finance.jar my-wallet.txt
```
## Тестовые аккаунты (для проверки работы)
При первом запуске приложения база данных пуста. Если вы хотите сразу проверить работу программы на готовых данных (включая переводы между пользователями), используйте следующие тестовые аккаунты:

Пользователь 1: Логин: alice, Пароль: 123

Пользователь 2: Логин: bob, Пароль: 456

Что уже есть на этих аккаунтах:

У alice добавлены доходы (Зарплата, Бонус), расходы (Еда, Развлечения, Коммунальные, Такси), а также установлены лимиты бюджетов по категориям.

С аккаунта alice был выполнен перевод в размере 1000 на аккаунт bob.

Вы можете зайти под любым из них, ввести команду stats и увидеть готовую статистику.

Если вы хотите начать с чистого листа — просто удалите файл wallets.txt из корневой папки проекта и перезапустите приложение.

## Проверка сценария из ТЗ
1. Запустите программу и войдите под alice / 123.
2. Выполните:
   income Зарплата 20000;
   income Зарплата 40000;
   income Бонус 3000;
   expense Еда 300;
   expense Еда 500;
   expense Развлечения 3000;
   expense Коммунальные 3000;
   expense Такси 1500;
   budget Еда 4000;
   budget Развлечения 3000;
   budget Коммунальные 2500;
   stats
3. В выводе должно быть: общий доход 63000.00, общие расходы 8300.00,
   по бюджету «Коммунальные» оставшийся лимит -500.00 (и предупреждение
   о превышении).
## Команды CLI

После входа в аккаунт доступны:

| Команда | Описание | Пример |
|---|---|---|
| `income <cat> <sum>` | добавить доход | `income Зарплата 20000` |
| `expense <cat> <sum>` | добавить расход | `expense Еда 300` |
| `budget <cat> <limit>` | установить/изменить бюджет | `budget Еда 4000` |
| `stats` | сводка: доходы/расходы/бюджеты | `stats` |
| `sum-expense <cat...>` | расходы по нескольким категориям | `sum-expense Еда Такси` |
| `sum-income <cat...>` | доходы по нескольким категориям | `sum-income Зарплата Бонус` |
| `transfer <login> <sum> [cat]` | перевод другому пользователю | `transfer bob 500` |
| `export <file>` | сохранить снимок в файл | `export backup.txt` |
| `logout` | выйти из аккаунта (с сохранением) | |
| `exit` | выйти из приложения (с сохранением) | |
| `help` | справка | |

В стартовом меню: `1` — вход, `2` — регистрация, `3` — выход.
